
# Student Study Planner

## Project Description

This is my project for CS399 Software Development Practicum.

The Student Study Planner is a Java program that will help
students organize their classes and assignments.

## Project Goals

- Add classes
- Add assignments
- View assignments
- Mark assignments as completed
- Remove assignments
- Save and load information

## Tools Used

- Java
- Visual Studio Code
- Git
- GitHub

## Current Progress

### Week 1
- Created the project folder
- Created Main.java
- Created a simple menu
- Added user input using Scanner
- Tested the menu options

## How to Run

1. Open the project folder in a terminal.
2. Compile the program:

   javac Main.java

3. Run the program:

   java Main
